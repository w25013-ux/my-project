# Golden Wheel Bike

Golden Wheel Bikeは、バイクショップをイメージして制作したシンプルなWebサイトです。
初めて訪れた方にもお店の雰囲気や商品が伝わるように、写真を中心とした見やすいデザインを心がけました。

## 公開サイト

サイトはこちらからご覧いただけます。

**[Golden Wheel Bikeを見る](https://w25013-ux.github.io/my-project/)**

## サイトについて

トップページでは、お店の紹介とHonda Trail 70を掲載しています。
商品ページでは、Honda、Yamaha、Suzukiのバイクをカード形式で紹介しています。
お問い合わせページも用意し、必要なページへ迷わず移動できるシンプルな構成にしました。

## 主なページ

- **Home** — ショップの紹介とHonda Trail 70の特集
- **Products** — 販売しているバイクの商品一覧
- **Contact** — お問い合わせフォーム

## 掲載しているバイク

- Honda Click 125
- Yamaha R6
- Suzuki GSX
- Honda Trail 70

## 使用した技術

- HTML
- CSS
- GitHub Pages

パソコンだけでなくスマートフォンでも見やすいように、画面幅に合わせてレイアウトが変わるレスポンシブ表示に対応しています。

## ファイル構成

```text
my-project/
├── index.html       # Homeページ
├── product.html     # 商品ページ
├── contact.html     # お問い合わせページ
├── index.css        # Homeページのスタイル
├── product.css      # 商品ページのスタイル
├── contact.css      # お問い合わせページのスタイル
└── images/          # サイトで使用する画像
```
